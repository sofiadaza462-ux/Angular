# AgroControl CBA

Aplicación monolítica en Python para el control de productos, lotes productivos, inventario, ventas y alertas en el contexto agropecuario del Centro de Biotecnología Agropecuaria (CBA).

## Requisitos
- Python 3.8 o superior

## Estructura del proyecto
- `main.py`: Punto de entrada único y lógica principal.
- `data/`: Almacenamiento local en archivos JSON.

## Ejecución
```bash
python main.py
